Free layout: the notes in the order you played them, with no rhythm. Record to the click as usual. A new measure starts after a pause (or each bar of the click, set in New measure at). Click between two notes to put a bar line there, click a bar line to take it away. Click a note and type to change the fret, Delete removes it, ⌘+click adds or removes single notes from a choice, X marks it muted, Shift+click a second note (or Shift+drag a box, or ⇧← ⇧→) to choose several: ⌘C ⌘X ⌘V, Delete, or Beam (or B) to join it with a beam, ← → step through the notes. To add a note: click a note and press Enter (after it) or ⇧Enter (before it), pick the string with ↑ ↓ and type the fret; Enter again keeps adding. Typing a fret on another string at a note adds it to that chord. Switch Layout back to Rhythm any time: the timing is still there.

Uses your MIDI and tuning settings, with one channel per string for exact positions. Adding and editing: click a string at any count (or a note) to place the cursor, then type the fret (two digits for 10–24). ← → or Enter move along the counts, ↑ ↓ change string, Delete removes, X marks a note muted, Shift+click, Shift+drag, ⇧← ⇧→ or ⌘A (all) chooses several notes for ⌘C ⌘X ⌘V, Delete, ⌥← ⌥→ and ⇧↑ ⇧↓, + − nudge the fret, ⌥← ⌥→ move the note, ⇧↑ ⇧↓ move it to the next string at the same pitch, Esc leaves. Each beat picks straight or triplet from how you played it; click a beat number to set it by hand (automatic → straight → triplet → 16th triplet). Changing Count re-snaps the same take.

Works like Finder's column view: click a folder to open it in the next column. Right-click (or Control-click) a column for New Folder; right-click a folder or item to open, rename or delete it. Drag anything into a folder, onto another column, or between items to reorder; hold a dragged item over a folder to open it. Double-click a name to rename.
